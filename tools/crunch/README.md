Lua source compressor by [mpmxyz](https://github.com/mpmxyz/ocprograms), MIT (see `LICENSE`).

`bin/` and `lib/` are copied unchanged from `home/` of commit `872f3e9`, so that `build.lua` can minify without a Minecraft world. In-game the same program comes from `oppm install crunch`.

Run it with `../crunch.lua`, which fakes the OpenOS modules it expects.
